## OOP in JavaScript

This project was created to practice Object-Oriented Programming (OOP) concepts using JavaScript.

It contains three main classes that represent different types of attacks in a simple combat system:

Ataque → Base class that defines common properties (player, type, name, damage) and the att() method that displays the action.

AtaqueFisico → Inherits from Ataque and adds the arma (weapon) attribute.

AtaqueMagico → Inherits from Ataque and adds the CustoMana (mana cost) attribute.

The project demonstrates the use of inheritance, polymorphism, and method overriding — core principles of OOP.
